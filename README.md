# 🔢 Number To Urdu & English Converter

A lightweight, web-based tool designed to convert numerical values into their full word equivalents in both **Urdu** and **English**. Built with pure HTML, CSS, and JavaScript for optimal speed and ease of deployment.

---

## ✨ Features

* **Dual Language Support:** Instant conversion to both English and Urdu text.
* **Real-time Conversion:** Words update dynamically as you type.
* **Large Number Support:** Handles units from thousands up to Millions, Billions, Lacs, and Crores.
* **Zero Dependencies:** Pure Vanilla JavaScript—no external libraries or heavy dependencies required.
* **Lightweight & Fast:** Minimal memory footprint, ensuring instant page loads.
* **Responsive Interface:** Fully accessible across desktop, tablet, and mobile browsers.
